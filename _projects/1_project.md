## 项目简介

本课程作业项目，按照规范化 AI 开发流程（Vibe → Spec → Harness → GitHub → GitHub Pages → TA-Claw）完成个人网站建设。

### 技术栈
| 技术 | 说明 |
|------|------|
| Jekyll | 静态网站生成器 |
| al-folio | 学术主题模板 |
| Tailwind CSS | 样式引擎 |
| GitHub Pages | 部署与发布 |

### 主要里程碑
1. **需求与规格** — 编写 PRD、Design、Checklist
2. **内容开发** — 替换个人内容，完成五个基础区块
3. **发布与提交** — GitHub Pages 上线 + TA-Claw 提交
