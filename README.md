# 李馨悦的个人网站

## 模板来源

- **模板**: [al-folio](https://github.com/alshedivat/al-folio) by alshedivat
- **许可证**: MIT

## 主要修改

1. 替换为个人内容（姓名、简介、技能、项目）
2. 添加作业文档（PRD、Design、Checklist）
3. 清理模板示例内容
4. 配置 GitHub Pages 部署
