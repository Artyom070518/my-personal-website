# PRD — 个人网站产品需求文档

## 项目概述
基于 al-folio Jekyll 模板的个人学术/职业网站，展示个人简介、技能、项目和联系方式。

## 目标访问者
- 课程教师与助教（作业验收）
- 潜在雇主或合作伙伴
- 同学与同行

## 访问者最先寻找的信息
1. 我是谁、什么专业方向
2. 我具备哪些能力和技能
3. 我有过什么项目或实践经历
4. 如何联系我

## 希望访问者看完后记住
- 深圳大学大数据专业学生，具备编程、设计、运营的综合能力
- 有丰富的校园组织工作和公益项目经验

## 本期必须包含的内容
| 区块 | 内容 |
|------|------|
| Hero | 姓名（李馨悦）、一句话定位、行动入口 |
| About | 个人简介、专业方向（大数据）、教育背景 |
| Skills | C/C++编程、亚克力周边设计、AI工具运用、全科家教、运营统筹 |
| Projects | 至少1个项目（可用本作业或标注"进行中"的项目） |
| Contact | GitHub主页链接、其他可选联系方式 |

## 本期明确不做的功能
- 不加入登录、数据库、支付、后台系统
- 不加入访客追踪和分析系统
- 不加入博客评论区
- 不加入多语言切换（仅中文）

## 完成标准
- 五个基础区块齐全，内容真实、无模板占位
- 桌面端和手机端均可正常阅读
- GitHub Pages 可公开访问
- Checklist 各项可通过截图和点击验证
