# PRD — 个人网站产品需求文档

## 项目概述
中文单页个人网站，展示个人简介、技能、项目经历和联系方式。

## 目标访问者
- 课程教师与助教（作业验收）
- 潜在雇主或合作伙伴
- 同学与同行

## 访问者最先寻找的信息
1. 我是谁、什么专业方向
2. 我具备哪些能力和技能
3. 我有过什么项目或实践经历
4. 如何联系我

## 希望访问者看完后记住
- 深圳大学大数据专业学生，具备编程、设计、运营的综合能力
- 有丰富的校园组织工作和公益项目经验

## 必须包含的内容
| 区块 | 内容 |
|------|------|
| Hero | 姓名（李馨悦）、照片、一句话定位、行动入口 |
| About | 个人简介、专业方向（大数据）、教育背景、GPA 4.09 |
| Skills | C/C++编程、设计创作、文案策划、运营统筹、英语能力 |
| Experience（经历） | 团委心理部、猫协、家教、课程实践四段经历 |
| Projects | 个人网站建设项目（本作业） |
| Contact | GitHub 主页链接 |

## 明确不做的
- 不加入登录、数据库、支付、后台系统
- 不加入多语言切换
- 不加入评论或博客功能

## 完成标准
- 六个区块齐全，内容真实
- 桌面端和手机端均可正常阅读
- GitHub Pages 可公开访问
- Checklist 各项可通过截图和点击验证
