# Design — 个人网站设计说明

## 页面区块与浏览顺序
1. **导航栏** — 固定在顶部，包含页面链接
2. **Hero/About 区** — 首屏显示姓名、照片、一句话定位和个人简介
3. **Skills 区** — 以列表/标签形式展示能力和工具
4. **Projects 区** — 项目卡片展示
5. **Contact 区** — 联系方式和社交链接

## 颜色与字体
- **主色调**：保持 al-folio 默认的浅色/深色模式
- **字体**：Roboto（正文）+ Roboto Slab（标题），由模板提供
- **风格**：简洁、学术、干净，以内容为主

## 风格定位
- 不需要复杂动画或特效
- 信息清晰、区块分明、便于浏览
- 保持 al-folio 原有的干净学术风格

## 桌面端要求
- 宽屏布局，左侧个人简介，右侧照片
- 导航栏固定顶部
- Skills 和 Projects 使用网格/卡片布局

## 移动端要求
- 窄屏导航自动折叠为汉堡菜单
- 内容区块按从上到下顺序排列
- 图片自适应缩放，文字不溢出

## 关键文件职责
| 文件 | 职责 |
|------|------|
| _config.yml | 站点全局配置：标题、姓名、描述 |
| _pages/about.md | 首页/关于页内容 |
| _data/socials.yml | 社交链接配置 |
| _data/cv.yml | 技能和经历数据 |
| ssets/img/ | 个人照片和图片资源 |
| docs/prd.md | 产品需求文档 |
| docs/design.md | 本文档 |
| docs/checklist.md | 验收清单 |

## 保留模板的部分
- 整体布局和响应式设计
- Tailwind 样式系统
- 深色/浅色模式切换
- 导航和页脚结构

## 修改的部分
- _config.yml：更换姓名、描述、URL
- _pages/about.md：替换为真实个人介绍
- _data/socials.yml：更新联系方式
- ssets/img/：替换为个人照片

## 图片来源
- 个人照片：由用户自行提供
- 模板原有图片：将替换或移除
